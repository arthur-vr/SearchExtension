# Operator Implementation Guide\n\n## Adding a New Operator\n\n1. Create a new folder under `src/` (e.g., `src/my_new_operator/`)\n2. Create `__init__.py` with `register()` and `unregister()` functions\n3. Register in `src/__init__.py`:\n   - Add import: `from . import my_new_operator`\n   - Add to `MODULE_REGISTRY` list\n   - Add `BoolProperty` in `SearchExtensionPreferences`\n\n## Making Operators Searchable (F3 Search)\n\nTo ensure your operator appears in the F3 search menu, register it to `VIEW3D_MT_object`:\n\n```python\nimport bpy\nfrom . import operator\n\ndef menu_func(self, context):\n    self.layout.operator(operator.F3UTILS_OT_your_operator.bl_idname)\n\ndef register():\n    bpy.utils.register_class(operator.F3UTILS_OT_your_operator)\n    bpy.types.VIEW3D_MT_object.append(menu_func)\n\ndef unregister():\n    bpy.utils.unregister_class(operator.F3UTILS_OT_your_operator)\n    bpy.types.VIEW3D_MT_object.remove(menu_func)\n```\n\n**Important**: Using `bpy.types.VIEW3D_MT_object.append(menu_func)` makes the operator always visible in F3 search results.\n\n## Required: Use Shared Constants\n\nAlways import and use constants from `_commons/constants.py`:\n\n```python\nfrom .._commons.constants import ADDON_NAME, ADDON_VERSION, ADDON_LABEL_SUFFIX\n```\n\n## Persistent Storage Pattern\n\nFor values that persist across Blender sessions, follow the pattern in `src/render_save_image/external_storage.py`:\n\n```python\n# Key pattern\nSERVICE_NAME = "my_service"\nKEY_SOME_VALUE = "some_value"\nDEFAULT_VALUE = {KEY_SOME_VALUE: ""}\n\nclass MyExternalStorage:\n    def __init__(self):\n        self.file_path = os.path.join(\n            bpy.utils.user_resource('SCRIPTS'),\n            "addons",\n            f"{ADDON_NAME}_{ADDON_VERSION}_{SERVICE_NAME}.json"\n        )\n        self.data = self.load_data()\n    # ... implement load_data(), save_data(), get(), set()\n```
