# Post-Implementation Checklist\n\nAfter completing your implementation, you **MUST**:\n\n## 0. Update Version Number\n\nIncrement the version in `src/__init__.py` before building.\n\n## 1. Register in `src/registry.py`\n\nRegister your new operator in the registry so it appears in preferences and can be toggled:\n\n```python\n# Add your operator to the OPERATOR_REGISTRY\nOPERATOR_REGISTRY = {\n    # ... existing operators\n    "my_new_operator": {\n        "label": "My New Operator",\n        "description": "What it does",\n    },\n}\n```\n\n## 2. Update `README.md` (project root)\n\nDocument your new feature for users:\n- Add to the feature list\n- Include usage instructions\n- Add any relevant screenshots/gifs if applicable\n\n## 3. Build\n\nRun: `cd bin/; pnpm build`\n\n---\n\n# Operator README Template\n\nWhen creating a README.md for an operator folder (e.g., `src/<operator_name>/README.md`), follow this structure:\n\n```markdown\n# <Operator Name>\n\n## Demo Link (x.com)\n\n## Description\nEnglish:\n<Brief description in English>\n\n日本語:\n<日本語での説明>\n\n## Download\nEnglish:\nThis is part of the Search Extension addon.\n[Download](https://github.com/arthur-vr/SearchExtension/releases)\n\n## How to use\n![Screenshot](./images/demo_xxx.png)\n\nEnglish:\n- Step-by-step instructions\n\n日本語:\n- 日本語での手順\n\n## Panel Description (if applicable)\n![Panel](./images/demo_panel.png)\n\n## Differences from other tools\n## Q&A\n```\n\n## README Structure Guidelines\n\n| Section | Required | Notes |\n|---------|----------|-------|\n| Title | Yes | Use `# <Operator Name>` |\n| Demo Link | Optional | Link to X/Twitter demo |\n| Description | Yes | Always bilingual (EN/JP) |\n| Download | Yes | Standard link to releases |\n| How to use | Yes | Include screenshots, bilingual |\n| Panel Description | Optional | If the feature has UI panels |\n| Differences | Optional | Highlight unique features |\n| Q&A | Optional | Common questions, bilingual |\n\n## Image Assets\n\nStore screenshots in `src/<operator_name>/images/`:\n```\nsrc/<operator_name>/\n├── __init__.py\n├── README.md\n└── images/\n    ├── demo_search.png\n    └── demo_panel.png\n```
