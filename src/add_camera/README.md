# Add Camera

## Demo Link (x.com)


## Description
English:
Add a camera with preset resolution settings. If objects are selected, the camera automatically positions itself to frame them in the view.

日本語:
解像度プリセット付きのカメラを追加します。オブジェクトが選択されている場合、カメラは自動的にそれらをフレーミングする位置に配置されます。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Press F3 and search for `Add Camera`
- Select resolution preset from the dialog
- Optionally adjust camera rotation and location
- If objects are selected before invoking, the camera will frame them automatically

日本語:
- F3を押して `Add Camera` を検索
- ダイアログから解像度プリセットを選択
- 必要に応じてカメラの回転と位置を調整
- 実行前にオブジェクトを選択していると、自動的にフレーミング

## Panel Description
English:
- **Resolution Presets**: 1024x1024, 1920x1080, 1080x1920, 2048x2048, 3840x2160, 1024x1792, 1792x1024
- **Camera Rotation**: Adjust X, Y, Z rotation angles
- **Camera Location**: Set X, Y, Z coordinates (used when no objects selected)

日本語:
- **解像度プリセット**: 1024x1024, 1920x1080, 1080x1920, 2048x2048, 3840x2160, 1024x1792, 1792x1024
- **カメラ回転**: X, Y, Z軸の回転角度を調整
- **カメラ位置**: X, Y, Z座標を設定（オブジェクト未選択時に使用）

## Differences from other tools
English:
- **Auto-framing**: Automatically calculates optimal distance to frame selected objects
- **AI-friendly presets**: Includes 1024x1792 and 1792x1024 for AI image generation

日本語:
- **自動フレーミング**: 選択オブジェクトを収めるための最適な距離を自動計算
- **AI対応プリセット**: AI画像生成に適した1024x1792と1792x1024を含む
