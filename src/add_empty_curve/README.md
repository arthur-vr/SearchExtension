# Add Empty Curve

## Demo Link (x.com)


## Description
English:
Add an empty curve object (with no control points) to the scene. Useful for creating curve-based setups from scratch.

日本語:
空のカーブオブジェクト（制御点なし）をシーンに追加します。ゼロからカーブベースのセットアップを作成する際に便利です。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Press F3 and search for `Add Empty Curve`
- Select curve type from the dialog (Bezier, NURBS, or Poly)
- The empty curve is created and selected

日本語:
- F3を押して `Add Empty Curve` を検索
- ダイアログからカーブタイプを選択（Bezier, NURBS, Poly）
- 空のカーブが作成され選択されます

## Panel Description
English:
- **Curve Type**: Bezier, NURBS, or Poly

日本語:
- **カーブタイプ**: Bezier, NURBS, または Poly

## Differences from other tools
English:
- **Truly Empty**: Unlike Blender's default curve primitives, this creates a curve with no control points

日本語:
- **完全に空**: Blenderのデフォルトカーブプリミティブとは異なり、制御点のないカーブを作成
