# Add Empty Mesh

## Demo Link (x.com)


## Description
English:
Add an empty mesh object (with no vertices) to the scene. Useful for procedural workflows or as a starting point for custom geometry.

日本語:
空のメッシュオブジェクト（頂点なし）をシーンに追加します。プロシージャルワークフローやカスタムジオメトリの開始点として便利です。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Press F3 and search for `Add Empty Mesh`
- The empty mesh is instantly created and selected

日本語:
- F3を押して `Add Empty Mesh` を検索
- 空のメッシュが即座に作成され選択されます

## Differences from other tools
English:
- **No Dialog**: One-click creation without any parameters
- **Zero Vertices**: Creates a mesh data-block with absolutely no geometry

日本語:
- **ダイアログなし**: パラメータなしでワンクリック作成
- **頂点ゼロ**: ジオメトリを一切含まないメッシュデータを作成
