# Add Empty Object

## Demo Link (x.com)


## Description
English:
Add an empty object to the scene with selectable display type. Empties are useful as parent objects, placeholders, or reference points.

日本語:
表示タイプを選択可能な空オブジェクトをシーンに追加します。エンプティは親オブジェクト、プレースホルダー、参照点として便利です。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Press F3 and search for `Add Empty Object`
- Select the empty type from the dialog
- The empty is created at the 3D cursor location

日本語:
- F3を押して `Add Empty Object` を検索
- ダイアログからエンプティタイプを選択
- 3Dカーソル位置にエンプティが作成されます

## Panel Description
English:
- **Empty Type**: Plain Axes, Arrows, Single Arrow, Circle, Cube, Sphere, Cone, Image

日本語:
- **エンプティタイプ**: Plain Axes, Arrows, Single Arrow, Circle, Cube, Sphere, Cone, Image

## Differences from other tools
English:
- **Quick Access**: All empty types accessible from F3 search in one dialog

日本語:
- **クイックアクセス**: F3検索から1つのダイアログで全エンプティタイプにアクセス可能
