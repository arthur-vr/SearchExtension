# Add Image Node

## Demo Link (x.com)


## Description
English:
Add a material with an Image Texture node connected to Principled BSDF to selected mesh objects. If an image is active in the Image Editor, it will be automatically assigned.

日本語:
選択したメッシュオブジェクトに、Image TextureノードをPrincipled BSDFに接続したマテリアルを追加します。Image Editorで画像がアクティブな場合、自動的にその画像が割り当てられます。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Select one or more mesh objects
- (Optional) Open an image in the Image Editor
- Press F3 and search for `Add Image Node`
- Materials are created/updated with the image texture setup

日本語:
- 1つ以上のメッシュオブジェクトを選択
- （オプション）Image Editorで画像を開く
- F3を押して `Add Image Node` を検索
- 画像テクスチャ設定でマテリアルが作成/更新されます

## Differences from other tools
English:
- **Auto-detect Image**: Automatically uses the active image from Image Editor
- **Batch Processing**: Applies to all selected mesh objects at once

日本語:
- **画像自動検出**: Image Editorのアクティブ画像を自動使用
- **一括処理**: 選択した全メッシュオブジェクトに一度に適用
