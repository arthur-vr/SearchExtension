# Input Console

## Demo Link (x.com)


## Description
English:
A simple utility to input text and print it to Blender's console. Useful for debugging or logging custom messages during development.

日本語:
テキストを入力してBlenderのコンソールに出力するシンプルなユーティリティです。開発中のデバッグやカスタムメッセージのログに便利です。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Press F3 and search for `Input Console`
- Enter text in the input field
- The text is printed to Blender's system console and info bar

日本語:
- F3を押して `Input Console` を検索
- 入力フィールドにテキストを入力
- テキストがBlenderのシステムコンソールと情報バーに出力されます

## Panel Description
English:
- **Input**: Text field for entering the message

日本語:
- **入力**: メッセージを入力するテキストフィールド

## Differences from other tools
English:
- **Quick Debug**: Faster than opening Python console for simple log messages

日本語:
- **クイックデバッグ**: シンプルなログメッセージにはPythonコンソールを開くより高速
