# Move Object to Center of View

## Demo Link (x.com)


## Description
English:
Move selected objects to the center of the current 3D viewport. The objects are placed at the view's focus point (where the viewport is looking at).

日本語:
選択したオブジェクトを現在の3Dビューポートの中心に移動します。オブジェクトはビューのフォーカスポイント（ビューポートが見ている場所）に配置されます。

## Download
English:
This is part of the Search Extension addon.
[Download](https://github.com/arthur-vr/SearchExtension/releases)

## How to use
English:
- Select one or more objects in the 3D Viewport
- Navigate the view to where you want the objects
- Press F3 and search for `Move Object to Center of View` (or `mocv`)
- Objects are instantly moved to the view center

日本語:
- 3Dビューポートで1つ以上のオブジェクトを選択
- オブジェクトを移動したい場所にビューをナビゲート
- F3を押して `Move Object to Center of View`（または `mocv`）を検索
- オブジェクトがビュー中心に即座に移動します

## Differences from other tools
English:
- **View-based Placement**: Uses the 3D cursor alternative - place objects where you're looking
- **Shortcut Alias**: Searchable as `mocv` for quick access

日本語:
- **ビューベース配置**: 3Dカーソルの代替として、見ている場所にオブジェクトを配置
- **ショートカットエイリアス**: `mocv` でも検索可能でクイックアクセス
